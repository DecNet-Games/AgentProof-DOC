# AgentProof-DOC

Documentation site source for **AgentProof — Agent Edit Receipts, Audit Log & Session Rollback for Unity** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/AgentProof-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Home Window, the Change Journal, Receipts & Verdicts, Watch Modes, Session Review, Audit Log Export, Rollback, the Guided Trial, Checkpoints, Conflict Detection, the Approval Gate, Code-Watch, Settings, Editions (Standard vs Studio), What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- `assets/images/`, `assets/videos/` — the product's real captures and demo media

AgentProof itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
