# Getting Started
{: .no_toc }

AgentProof works in one Editor window and one loop: **watch** the agent edit, **read the receipts back**, **roll back** anything that did not land the way the agent claimed. This section takes you from the Asset Store download to your first verified session.

- [Installation]({{ site.baseurl }}/docs/installation/) — import the package and run the one-click Setup.
- [Quick Start]({{ site.baseurl }}/docs/quick-start/) — the Guided Trial end to end: five practice edits, their receipts, and the rollback.
- [The Home Window]({{ site.baseurl }}/docs/home-window/) — what every section of AgentProof Home does.

> **Pro Tip:** You do not need an agent session of your own ready to try AgentProof. The package ships the **Guided Trial** — a practice session of five edits, including one silent edit that never lands — so the full loop works minutes after import.
