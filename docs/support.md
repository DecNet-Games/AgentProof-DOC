## What to attach

AgentProof's own evidence is the best bug report it can give you:

1. **Export the audit log** for the affected session (Session Review → Export Audit Log) and attach the JSON and the Markdown summary.
2. The receipt rows in question — the target, before/after values and verdict are usually enough to start from.
3. Your Unity version (2022.3 LTS or Unity 6), your edition (Standard or Studio), and whether the edit came through a bridge (which one) or a terminal agent on disk.
